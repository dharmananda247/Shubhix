# Shubhix AI v2.1

Android voice assistant with two companions (DJ and SHUBHU), powered by Gemini.

## What is in 2.1
- Reliability: voice recovery (retry + Google voice box), built-in DNS fallback and Connection check,
  model auto-fallback, phone-specific battery guides, honest replies, "Heard" text, clearer errors
- Everyday commands: calls with nicknames and auto-dial (Yes/No card first time), WhatsApp and SMS,
  music, YouTube play, gallery, camera, maps, settings pages, preferred music app, Hindi/Odia/Bengali listening
- Pro agent: screenshot vision fallback, YouTube recipe, saved skills, task log with run-again,
  blocked-app list, ask-before-sending card
- For everyone: home buttons, first-run checklist, command test, home-screen widget, backup/restore,
  update checker
- Neon Gaming theme (default) with Classic Purple option
- Renamed to Shubhix AI (same package, so it installs over the previous version)

## Build
Push to GitHub. Actions builds a signed APK and publishes it on Releases.
